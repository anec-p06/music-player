# 🎵 Desktop Music Player

A desktop music player developed using HTML, CSS, JavaScript and Electron.

## ✨ Features

- 🎵 Music playback
- 💿 Album artwork and album selection
- ⏯️ Custom playback controls
- 🔊 Volume controls
- ⌨️ Keyboard shortcuts
- 📊 Track progress tracking
- 🖥️ Desktop application built with Electron
- 🎨 Custom user interface

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Electron
- Node.js
- npm

## 🚀 Running the Project

### Requirements

- Node.js
- npm

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/anec-p06/music-player.git
cd music-player
npm install
```
### 📚 About the Project

This project was developed to explore desktop application development using web technologies and Electron.

The application combines HTML and CSS for the user interface with JavaScript for application logic and Electron for the desktop environment.

The project also provided experience with structuring a desktop application, handling user interactions, implementing media controls and working with Node.js and npm.
